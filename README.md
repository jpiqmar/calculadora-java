# Aplicación de Calculadora Orientada a Objetos 📱

## Descripción General
Este repositorio contiene el código fuente de una aplicación de calculadora desarrollada en **Java**. El proyecto se diseñó aplicando los principios de la **Programación Orientada a Objetos (POO)** para asegurar un código modular, escalable y fácil de mantener.

## Características Principales
*   **Diseño POO:** Implementación de clases, herencia y encapsulamiento para separar la lógica de la interfaz de usuario de las operaciones matemáticas.
*   **Motor Matemático Robusto:** Capaz de manejar las operaciones aritméticas estándar, incluyendo control de errores para casos límite (ej. división por cero).
*   **Sistema de Construcción Gradle:** Estructurado mediante Gradle para facilitar la compilación y la gestión de dependencias.

## Stack Tecnológico
*   **Lenguaje:** Java
*   **Herramienta de Construcción:** Gradle
*   **IDE:** IntelliJ IDEA
